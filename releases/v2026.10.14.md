## 修复内容

- 公网 IP 更新并经 Cloudflare 确认成功后，MiniGate 会刷新本机 sing-box 和 dnsmasq 的 DNS 缓存，减少局域网设备继续解析到旧公网地址。
- sing-box 通过本机 Clash API 的 `POST /cache/dns/flush` 清缓存；dnsmasq 只接收 `SIGHUP`，不会停止进程或丢失 DHCP 租约。
- 整个过程不会重启 Open-Box、sing-box 或 MiniGate 反向代理，不主动中断现有外网连接。

## 触发边界

- Cloudflare 记录实际新增、改写或清理同名重复记录后触发一次。
- Cloudflare 已是新地址、但 MiniGate 本地仍保存旧 IP 时也触发一次，用于补偿上一次更新后的本地缓存遗漏。
- 普通定时检查确认地址未变时不清缓存；Cloudflare 更新失败时也不清缓存。
- sing-box 接口或 dnsmasq 不存在、暂时不可用时只记录诊断，不把已经成功的公网 DDNS 更新标记为失败。

## 兼容性说明

- Open-Box 的 sing-box 配置存在时，MiniGate 会从本机配置读取 Clash API 地址所需的密钥；密钥不写入日志。
- 没有安装 Open-Box/sing-box 的设备会跳过对应步骤，dnsmasq 刷新仍可独立执行。
- 已经缓存到手机、电脑或浏览器进程内的旧答案，仍可能保留到原 TTL 到期；路由器无法主动清除每台终端的进程内缓存。
