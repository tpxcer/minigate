## 审查问题与界面优化

这一版集中修复代码审查中发现的问题，并调整各页面界面。界面名称统一为 **MiniGate**；OpenWrt 包名仍为 `minigate`。

### 修复

- 通配符主域名停用或删除后，其子域名不再退回成 443 端口的明文 HTTP 站点。之前在同一端口还有 HTTPS 规则时，这还会让 Nginx 因两个默认站点而无法加载。现在子域名随主域名一起停用，也可以单独停用。
- 同一端口同时配置了 HTTP 和 HTTPS 规则时，冲突的规则会被跳过，并在总览页说明原因，不再生成 Nginx 无法加载的配置。
- 配置检查失败时，自动恢复上一份可用配置，正在运行的站点不受影响。生成过程加了锁，保存设置、证书续期和软件更新同时触发时不会互相覆盖。
- 登录防护支持 IPv6 来源；白名单支持 IPv4/IPv6 和任意前缀长度。防火墙没有接受的封禁会如实记录为失败，不再误记为已封禁。
- 封禁集合和拦截规则随防火墙每次重载自动加载；重载清空的封禁会在 30 秒内恢复，之前最多要等 5 分钟。
- DDNS 只向 Cloudflare 推送公网地址。软路由在上级路由 NAT 之后时，网卡上的内网地址会被拒绝，并提示改用外部 URL。
- 日志页「全部」改为按时间合并各来源。之前只是把各文件首尾相接后取最后 200 行，实际几乎看不到 DDNS 和证书日志。

### 可靠性与安全

- 服务改由 procd 管理：Nginx 和登录防护异常退出后自动拉起，停止时结束所有子进程。LuCI「保存并应用」后只重载受影响的部分，不再轮询等待配置写入。
- DDNS 与证书的运行状态移到 `/var/run/minigate`，定时检查不再反复改写 `/etc/config/minigate`。升级时会清除旧版写在配置文件里的状态字段。
- acme.sh 固定为 3.1.6，下载后先校验 SHA-256 再安装。证书剩余超过 30 天时，手动签发不会重复申请，避免触发 Let's Encrypt 频率限制。
- 签发证书和手动同步 DDNS 改在后台执行，页面轮询结果，不受网页请求超时影响。
- 外部 IP 查询默认改用 HTTPS 地址，失败时依次回退。
- 所有站点自动支持 WebSocket。
- 访客归属地优先查随包的离线地址库；境外地址才用 HTTPS 接口查询，缓存有数量上限。
- 定时任务只管理本插件的脚本，不会再误删用户自己写的、名字里含 minigate 的任务。
- 移除旧版地区日志扫描。已启用旧版限制的配置，升级时迁移为反代请求前准入，同时移除旧的全局防火墙集合。

### 界面

- 总开关移到总览页顶部，未启用时会显示提示。
- DDNS 卡片列出全部记录，按最差的状态着色。
- 证书卡片和证书页显示到期日期、剩余天数，并标出测试证书。
- 反代地址可以直接点击，配置问题会显示在反代卡片里。
- 卸载移到总览底部的「危险操作」区。
- 日志页新增登录防护和软件更新来源；往上翻看旧日志时，不再被自动拉回底部。
- DDNS 手动同步在原位置更新状态，不再刷新整页，表单里未保存的修改不会丢；有未保存修改时会先提示。
- 反代页改为规则在前、高级设置在后，「监听 IPv6」也移到这里；地区改用复选框，启用开关统一为勾选框；没有域名时会引导到动态 DNS 页。
- 登录防护页的「清空全部封禁」移到列表底部；手动封禁支持 IPv6。
- DDNS、反代、证书和日志页跟随 LuCI 深色主题。
- 表单增加校验：域名、Zone ID、API 令牌、检查间隔、失败阈值和白名单。

## 升级说明

- 升级后服务改由 procd 管理。LuCI 的「保存并应用」会自动重载服务，不需要再手动重启。
- 防火墙下次重载时才会从随包文件加载新的封禁集合；在此之前，登录防护会自行创建同名集合和规则，封禁照常生效。
- 旧版写在配置文件里的 DDNS 和证书状态字段会被清除。升级后首次同步前，状态显示为「未同步」。
- 子域名所属的通配符主域名未启用时，该子域名不再生效。如果之前依赖这种回退的明文访问，请启用主域名，或改为普通代理规则。

## 验证

本地 127 项测试全部通过，无跳过。其中包括 LuaJIT 下的 LuCI 页面加载与表单校验、真实 Nginx 的转发与拦截、子域名跳过、端口冲突、配置回滚、登录防护 IPv6 解析与 procd 停止，以及 DDNS 公网地址校验。

另外两项检查：

- 用 `nft -c` 在 OpenWrt 25.12 上校验了封禁 include 文件，校验结果不写入防火墙。
- 用 `sh -n` 检查了 12 个 Shell 脚本的语法。

本次不自动更新路由器。
